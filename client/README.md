# Мониторинг ключевых показателей БД Postgresql

Frontend - React\
Backend - NestJS 

Основная цель приложения - общий взгляд на состояние базы данных, оценка работы автовакуума, анализ использования индексов, анализ ключевых параметров Postgres и др.

## Скрипты запуска

В корневой директории проекта:

### `npm run start:dev`

Запускает бэкенд приложения в режиме разработчика.\
[http://localhost:3000](http://localhost:3000) для просмотра в браузере.\

В папке client:

### `npm start`

Запускает frontend часть
