# Изменения в ветке deepseek_version

## Бэкенд (NestJS)
1. **Удалена зависимость от TypeORM** – теперь используются прямые пулы `pg`.
2. **ConnectionManagerService** переписан для управления пулами подключений.
3. **Системные метрики** (RAM, CPU, версия ОС) вынесены на уровень Node.js (модуль `os`, чтение `/proc` через `fs`).
4. **QPS** переделан – измеряется разницей между двумя замерами `pg_stat_statements` без блокировки `pg_sleep`.
5. **Добавлено кэширование** для медленно меняющихся данных (TTL 30 с).
6. **Базовая аутентификация** через API-ключ (заголовок `X-API-Key`).
7. **Healthcheck** эндпоинт `/health`.
8. **Улучшена обработка ошибок** – все ответы содержат понятные сообщения.

## Фронтенд (React)
1. **Добавлена пагинация** в виджетах:
   - Мёртвые кортежи
   - Статистика индексов
   - Тяжёлые запросы
2. **Улучшена обработка ошибок** – показывается текст ошибки вместо "нет данных".
3. **Мелкие исправления** (key props, типы).

## Docker
- Добавлен `healthcheck` для бэкенда.
- Исправлены переменные окружения.

## Документация
- Обновлён README.
- Добавлен `.env.example`.

Все SQL-запросы (кроме QPS) и прямые вызовы `/proc` через `pg_read_file` **не тронуты**.
