# pg-health

Мониторинг PostgreSQL

## Основные возможности backend
- Просмотр состояния БД (размеры ОС, версии, RAM, CPU, объем БД, расчет QPS, статистика подключений, параметры работы автовакуума, ТОП-10 самых тяжелых запросов, )
- Анализ критичных параметров PG (work_mem и др.) и рекомендации по возможным улучшениям
- Просмотр блокировов, зависших транзакций
- Просмотр недействительных и неиспользуемых индексов
- Просмотр состояния репликации

## Основные возможности frontend
- Каждый показатель может быть произвольно изменен в размерах
- Каждый показатель может быть перемещен в рамках вкладки
- Каждый показатель имеет кнопку перезагрузки, обновляя данные из БД
- Вверху каждого раздела есть сводка проблем, содержащая перечень моментов, на которые надо обратить внимание в первую очередь
- Наличие тем оформления: светлая, темная, контрастная
- Возможность экспорта вкладки в PDF
- Состояние внешнего вида виджетов сохраняется в локальном store (React)

## Запуск в докере
```bash
cp .env.example .env
# заполните .env
docker-compose up -d
```

## Запуск локально
Фронтенд: `cd client && npm start`
Бэкенд: `npm run start:dev`
Приложение работает по адресу: http://localhost:3001/
